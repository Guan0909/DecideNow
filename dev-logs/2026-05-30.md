## 遇到的问题
- shadcn v4 默认使用 Tailwind v4 语法（`@import "shadcn/tailwind.css"`），与 Next.js 14 的 Tailwind v3 不兼容 → 手动重写 globals.css 为 Tailwind v3 CSS 变量方案
- shadcn 生成的 button 组件依赖 `@base-ui/react`（v4 专用）→ 重写为基于标准 `<button>` 元素的独立组件
- Windows 目录名 `DecideNow` 含大写字母 → 先创建临时目录再移动文件
