# DecideNow 功能清单

## 一、首页 · 智能入口

| 功能 | 描述 |
|------|------|
| AI 打字机 Placeholder | 自动轮播提示语动画 |
| 自然语言输入框 | 一句话描述需求 |
| 时段智能标签 | 清晨/午间/午后/晚间/深夜，6 个时段自动匹配 |
| 标签随机池 | 51 个标签，每次刷新不同 6 个 |
| 定位辅助 | 一键获取位置 + 手动输入区域 |
| 双模式悬浮按钮 | 输入≥3 字后浮现"帮我决定"和"邀请朋友" |
| 加入投票入口 | 输入 6 位分享码直接进入房间 |
| 桌面 PWA | 添加到手机主屏幕，接近原生 App |

## 二、单人决策 · AI 工坊

| 功能 | 描述 |
|------|------|
| DeepSeek AI 生成 | 输入需求 → 3 个带评分选项 |
| 毛玻璃卡片画廊 | 左右滑动浏览 |
| 卡片堆叠虚影 | 后方卡片半透明层叠 |
| 动量滑动 | 快速轻扫或滑过 30% 自动切卡 |
| 弹簧回弹动画 | 松手超调回位 |
| 三维评分能量条 | 口味/氛围/预算 |
| AI 判词 | 个性化斜体推荐语 |
| 价格+地点标签 | 商圈+人均信息 |
| 选择结算动画 | 胜出放大+光环+印章 |
| 一键导航 | 跳转高德地图 |
| 一键分享 | 原生分享+剪贴板降级 |
| 重新决策 | 回到首页重来 |

## 三、多人投票 · 社交室

| 功能 | 描述 |
|------|------|
| 创建投票房间 | 输入主题+选项+设置 |
| AI 预填选项 | 自动生成带具体地点的选项 |
| 截止时间选择器 | 1h~7天，可视化网格按钮 |
| 匿名投票开关 | 参与者身份保密 |
| 6 位分享码 | 唯一房间标识 |
| 分享链接+分享码复制 | 一键复制 |
| 进度条即投票 | 点击进度条直接投票 |
| 实时轮询刷新 | 每 5 秒更新票数 |
| 投票理由 | 可选附加评论 |
| 拉票按钮 | 分享投票链接 |
| 截止/手动结束 | 自动或手动截止 |
| 结果页 | 胜出高亮+暖金动画 |
| 无需注册参与 | 打开链接即投 |

## 四、决策资产中心

| 功能 | 描述 |
|------|------|
| 历史记录列表 | 所有完成的决策 |
| 场景标签筛选 | 美食/出游/娱乐/购物/健身/其他 |
| 决策回溯 | 点击查看详情 |
| AI 采纳率标记 | 追踪是否选 AI 首推 |

## 五、北极星指标体系

| 事件 | 追踪内容 |
|------|----------|
| `visit` | 访问+新老用户识别 |
| `activate` | 发起决策（激活） |
| `ai_generated` | AI 响应耗时+选项数 |
| `decision_completed` | 🎯 北极星核心 |
| `share_clicked` | 分享动作 |
| `room_created` | 创建投票 |
| `vote_cast` | 投票参与 |
| `retry` | 重新决策 |
| `navigated` | 导航行为 |

## 六、设计系统

| 要素 | 规格 |
|------|------|
| 亮色主题 | 暖奶油底 + 暖陶土主色 + 金麦辅色 |
| 暗色主题 | 自动跟随系统偏好 |
| 触控规范 | 最小 44×44px |
| 对比度 | WCAG AA（≥ 4.5:1） |
| 动画 | 200ms 弹性动画 + 尊重 `prefers-reduced-motion` |
| 毛玻璃 | `backdrop-filter: blur(20px)` |

## 七、技术架构

| 层次 | 技术 |
|------|------|
| 框架 | Next.js 14 + React 18 |
| 样式 | Tailwind CSS 3 + shadcn/ui |
| AI | OpenAI SDK → DeepSeek API |
| 数据库 | PostgreSQL (Supabase) + Prisma ORM |
| 认证 | Supabase Auth（匿名） |
| 部署 | Vercel |
| 埋点 | 自建 Analytics API → Supabase |

## 八、完整路由

| 路由 | 页面 |
|------|------|
| `/` | 首页（输入+卡片+结果 全内联） |
| `/decide/[id]/card` | 决策详情 |
| `/history` | 历史记录 |
| `/room/create` | 创建投票 |
| `/room/[code]` | 投票参与 |
| `/room/[code]/result` | 投票结果 |

| API | 用途 |
|------|------|
| `/api/ai/parse` | 解析用户约束 |
| `/api/ai/generate` | 生成决策选项 |
| `/api/decisions` | 决策 CRUD |
| `/api/rooms` | 房间 CRUD |
| `/api/analytics` | 埋点上报 |
