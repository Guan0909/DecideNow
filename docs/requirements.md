# DecideNow - 产品需求文档

## 产品定位

**产品名称**：DecideNow —— 让每一个纠结都有答案

**一句话介绍**：用 AI + 社交投票，帮助年轻人在生活琐事和群体决策中快速做出选择，并沉淀成可分享的"决定时刻"。

**产品形态**：移动端优先的 Web 应用，无需安装，通过链接即可使用和分享。

## 目标用户

| 优先级 | 用户群 | 描述 |
|--------|--------|------|
| P0 核心 | 18-28 岁城市年轻人 | 朋友聚会多、日常选择困难（吃饭、出游、娱乐） |
| P1 次要 | 小型团队/家庭 | 需要快速达成一致的小决策场景 |

## 痛点场景

1. **一人纠结**：选项太多，标准模糊，决策疲劳（"中午吃什么？""周末去哪玩？"）
2. **多人拉扯**：群里讨论半天，没人拍板，聊天记录混乱，最后不了了之
3. **决策无痕**：决定完就忘，下次遇到同样场景又要重新来一遍

## MVP 功能范围

### 功能模块 A：智能输入引擎
- 自然语言解析（提取人数、预算、地点、口味、氛围等约束）
- 快捷标签（"午餐""约会""团建"等常见场景模板）
- 模糊容忍度设计（信息不全照样出推荐，标注缺失信息）

### 功能模块 B：AI 决策工坊（单人模式）
- 用户输入需求 → AI 生成 3 个具体选项
- 每个选项附带评分卡（口味/环境/预算匹配度 + AI 推荐语）
- 卡片式左右滑动浏览，点击选定
- 生成决策卡片，支持分享、收藏

### 功能模块 C：社交投票室（多人模式）
- 创建决定房间（AI 预填选项或手动填写）
- 生成唯一房间 ID 和分享链接
- 好友无需登录即可投票，可选附加理由
- 实时投票进度条，支持匿名/公开投票
- 截止时间或手动截止，结果高亮

### 功能模块 D：决策资产中心
- 自动生成决策卡片（背景图 + 选项 + 理由 + 结果 + 日期）
- 登录用户可查看历史决定，按标签分类
- 分享裂变（卡片署名"来自 DecideNow"，附带入口二维码）

## 北极星指标

每周完成的有意义决定数（选定选项且后续有"导航/收藏/分享"任一动作）

## 关键指标
- 激活率：访问后 1 分钟内发起一个决定的比例
- 分享率：完成决定后分享链接或卡片的比例
- 多人参与深度：每个投票房间平均参与人数、投票率
- AI 采纳率：用户最终选择 AI 首推选项的比例
