## 二、产品概述

### 2.1 一句话介绍

用 AI + 社交投票，帮助年轻人在生活琐事和群体决策中快速做出选择，并沉淀为可分享的"决定时刻"。

### 2.2 产品定位

| 维度 | 描述 |
|------|------|
| 产品形态 | 移动端优先的 Web 应用（PWA），无需安装，即点即用 |
| 目标用户 | 核心：18-28 岁城市年轻人；次要：小型团队/家庭 |
| 核心场景 | 日常吃喝玩乐决策（单人纠结 + 多人拉扯） |
| 差异化 | AI 自然语言输入 → 3 秒提需求，10 秒得结果 |

### 2.3 解决的核心痛点

| 痛点 | 现状 | 解决方案 |
|------|------|----------|
| 一人纠结 | 选项太多、标准模糊、决策疲劳 | AI 解析约束 → 生成 3 个带评分选项 |
| 多人拉扯 | 群里讨论半天、聊天记录混乱、无人拍板 | 创建投票房间 → 实时投票 → 自动出结果 |
| 决策无痕 | 决定完就忘、下次又重来 | 历史记录 + 场景标签 + 一键复刻 |

## 三、用户故事

| 优先级 | 故事 | 场景 |
|--------|------|------|
| P0 | 作为用户，我输入"三个人徐家汇吃辣人均 80"，希望 AI 直接给出 3 个具体餐厅选项 | 单人午餐决策 |
| P0 | 作为发起人，我创建一个投票，朋友们点链接就能投票，不用注册 | 周末聚会地点选择 |
| P1 | 作为用户，我想查看之前做的决定，下次直接复用 | 重复场景快速决策 |
| P1 | 作为发起人，我能看到实时的投票结果，截止后自动生成结果 | 多人决策收束 |
| P2 | 作为用户，我能把决策结果分享到微信/朋友圈 | 社交展示 |

## 四、功能架构

### 4.1 功能模块总览

```
DecideNow
├── 首页（智能入口）
│   ├── 自然语言输入框 + AI 打字机 Placeholder
│   ├── 时段智能标签推荐（51 个标签池）
│   ├── 位置感知（自动定位 + 手动输入）
│   ├── 双模式悬浮按钮（帮我决定 / 邀请朋友）
│   └── 加入投票入口（6 位分享码）
│
├── 单人决策（AI 工坊）
│   ├── DeepSeek AI 生成 3 个带评分选项
│   ├── 毛玻璃卡片画廊（滑动浏览）
│   ├── 三维评分能量条（口味/氛围/预算）
│   ├── 价格提示 + 地点标签
│   ├── 选择结算动画
│   └── 高德地图一键导航 + 分享 + 重新决策
│
├── 多人投票（社交室）
│   ├── 创建投票房间（主题 + 选项 + 设置）
│   ├── AI 预填选项（带具体地点推荐）
│   ├── 6 位分享码 + 链接复制
│   ├── 进度条即投票（融合交互）
│   ├── 实时轮询刷新（每 5 秒）
│   ├── 匿名投票 + 截止时间设置
│   └── 结果页（胜出高亮动画）
│
├── 决策资产中心
│   ├── 历史记录列表
│   ├── 场景标签筛选（美食/出游/娱乐/购物/健身）
│   └── 决策回溯
│
└── 北极星指标体系
    ├── 9 种用户事件埋点
    ├── 8 维看板 SQL
    └── sessionId 串联用户行为漏斗
```

### 4.2 核心流程

```
【单人决策】
首页输入 → AI 解析约束 → 生成 3 个选项卡片 → 滑动浏览 → 点击"就它了" → 结算动画 → 导航/分享/再来

【多人投票】
首页输入 → 跳转创建页 → AI 预填选项 → 设置截止时间 → 创建房间 → 分享码/链接 → 朋友投票 → 实时结果 → 截止出胜者
```

## 五、数据指标（北极星）

### 5.1 指标体系

| # | 指标 | 计算方式 | 用途 |
|---|------|----------|------|
| ① | 本周决策数 | `decision_completed` 7天计数 | 北极星，衡量产品活跃度 |
| ② | 激活率 | 激活会话 ÷ 访问会话 | 衡量首次体验转化 |
| ③ | AI 采纳率 | 选 AI 首推 ÷ 总决策 | 衡量 AI 推荐质量 |
| ④ | 分享率 | 分享次数 ÷ 完成决策数 | 衡量裂变引擎效率 |
| ⑤ | 模式分布 | 单人/多人占比 | 指导功能优先级 |
| ⑥ | AI 性能 | 平均/最小/最大响应 ms | 监控 AI 服务质量 |
| ⑦ | 每日趋势 | 按天聚合决策/房间/投票 | 发现周规律 |
| ⑧ | K 因子 | 新用户 ÷ 老用户 | 衡量病毒增长能力 |

### 5.2 增长飞轮

```
用户因决策困难使用产品 (工具价值)
  → 生成决策海报/投票链接并分享 (社交展示)
  → 朋友通过链接体验产品 (裂变引流)
  → 朋友成为新发起人 (飞轮闭环)
```

## 六、非功能需求

| 类型 | 要求 |
|------|------|
| 性能 | 首页首屏 < 3s，AI 生成 < 10s |
| 移动端 | 375px 基准，touch target ≥ 44px |
| 可访问性 | WCAG AA（对比度 ≥ 4.5:1），prefers-reduced-motion |
| 暗色模式 | 跟随系统偏好自动切换 |
| PWA | 可添加到主屏幕 |
| 无需登录 | 核心流程全免注册，匿名可用 |
| 埋点 | 9 事件全覆盖，sessionId 串联漏斗 |

## 七、技术方案概要

| 层次 | 技术选型 |
|------|----------|
| 前端框架 | Next.js 14 + React 18 |
| 样式 | Tailwind CSS 3 + shadcn/ui |
| AI 引擎 | OpenAI SDK → DeepSeek API (v4-flash) |
| 数据库 | PostgreSQL (Supabase 托管) + Prisma ORM |
| 实时通信 | Supabase REST API + 前端轮询 (5s) |
| 认证 | Supabase Auth（匿名登录） |
| 埋点 | 自建 Analytics API → Supabase |
| 部署 | Vercel + GitHub |
| 域名 | [decidenow.asia](https://decidenow.asia)（已上线） |
| 地图导航 | 高德地图 URI Scheme |
| 设计系统 | UI/UX Pro Max · Warm Minimalist |
