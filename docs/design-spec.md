# DecideNow - UI/UX 设计规范

## 设计原则

1. **极致短路径**：从打开到完成决策不超过 3 步
2. **移动端优先**：所有页面以 375px 宽度为基准设计，向上兼容
3. **少打字**：能用标签选的不用打字，AI 自动补全
4. **即时反馈**：每次操作 100ms 内有视觉响应

| 层级 | 大小 | 字重 | 用途 |
|------|------|------|------|
| H1 | 24px | Bold (700) | 页面标题 |

## 组件规范

### 卡片
- 圆角：16px
- 阴影：`0 2px 12px rgba(0,0,0,0.08)`
- 内边距：20px
- 卡片间距：16px
- 选中态：2px 主色边框 + 微阴影

### 按钮
- 主按钮：主色背景、白色文字、圆角 12px、高 48px
- 次按钮：主色边框、透明背景、主色文字
- 最小点击区域：44x44px（符合移动端无障碍标准）

### 输入框
- 圆角：12px
- 内边距：16px
- 占位符颜色：中灰 `#B2BEC3`
- 聚焦态：主色边框 2px

### 底部导航（如有）
- 高 56px + safe-area-inset-bottom
- 图标 24x24px
- 标签 10px

## 动画

- 卡片滑动：spring 动画，300ms
- 进度条：ease-out，500ms
- 页面过渡：fade 200ms
- 投票实时更新：数字弹跳 300ms

## 移动端适配

- 视口：`<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1, user-scalable=no">`
- 安全区域：使用 `env(safe-area-inset-*)`
- 触摸反馈：`:active` 态必须有视觉变化
- 键盘弹出：输入框自动上移，不被键盘遮挡
